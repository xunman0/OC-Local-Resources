# OC Local Resources: Food Pantries and Diaper Banks

A plain-language knowledge base of free food and diaper resources in Orange County, California. It is written in Markdown for Obsidian and organized so an AI assistant can find accurate, specific answers.

> [!important] Call before you go
> Hours change often, and some sites serve only residents, enrolled children, or registered clients. Call the site or dial **2-1-1** (211 OC) before making the trip.
>
> For the latest schedule at any **Second Harvest partner site**, contact Second Harvest Food Bank of Orange County at **949-653-2900** or **info@feedoc.org**.

## What's Inside

| Folder | What it contains |
|---|---|
| `00-Overview` | Scope, glossary, and rules for how the files are written |
| `03-Pantries-by-City` | One file per city, listing food pantries, school sites, senior grocery sites, Park-it Markets, and kids meal sites |
| `08-Diaper-Banks` | Free diaper distributions, mostly through the CAP OC Diaper Bank |

Start with `03-Pantries-by-City/_Index.md` for a list of all cities.

## Please Keep in Mind
- Most of this information is copied from the sources above and has **not** been confirmed with each site. Entries marked ✅ were checked on the organization's own website.
- Some details in the source lists appear to be typos or out of date. These are being checked.
- Notes like "may be for residents only" are cautious guesses based on the site's name, not confirmed rules.
- Nothing here is a guarantee of service. Sites may change hours, run out of supplies, or close without notice.

## Report a Correction
If you find wrong hours, a closed site, or a missing pantry, please open an issue in this repository with the site name, what's wrong, and how you know.
